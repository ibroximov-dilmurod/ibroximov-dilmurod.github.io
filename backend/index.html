О себе

Backend-разработчик: проектирую и веду сервисы на Python и FastAPI в Департаменте цифрового развития Ташкента. Сервисы держат около 350 запросов в секунду в пике при p95 150 мс и доступности 99,9%.

Отдельно веду собственный продукт MIRYAS AI: автономный ИИ-агент для рекламы в Meta, полностью развёрнутый в Google Cloud.

API И СЕРВИСЫ

  • Проектирую и веду REST API на FastAPI: 14 сервисов, ~350 запросов в секунду в пике, p95 150 мс, доступность 99,9%.
  • Держу контракт API в OpenAPI: схемы на pydantic, версионирование, обратная совместимость при изменениях.
  • Настроил аутентификацию и авторизацию по JWT и OAuth2 с разграничением прав по ролям.
  • Подключил 11 внешних систем по REST API, данные в JSON и XML проверяются по схеме. На нестабильных интеграциях — таймауты и повторы с экспоненциальной задержкой.
  • Передаю данные в реальном времени через WebSocket на панель операторов, задержка меньше секунды.

ДАННЫЕ И ПРОИЗВОДИТЕЛЬНОСТЬ

  • Спроектировал схемы PostgreSQL для 9 предметных областей, миграции на Alembic. Партиционирование и индексы ускорили ключевые запросы в 6 раз.
  • Кэш на Redis сократил ответ внутреннего API с 1,2 секунды до 150 мс.
  • Вынес тяжёлые операции в очереди Celery: до 200 тыс. задач в сутки, идемпотентность и повторы при сбоях.
  • Аналитические выборки увёл в ClickHouse (900+ млн строк): отчёты строятся за 1,5 секунды вместо 40 и больше не мешают основной базе.
  • Подключил полнотекстовый поиск на Elasticsearch по 3 млн обращений граждан, ответ быстрее 200 мс.
  • Регулярные фоновые расчёты веду в Apache Airflow: 38 DAG-ов, 99,6% запусков без ручного вмешательства.

ИНФРАСТРУКТУРА И КАЧЕСТВО КОДА

  • Упаковал 14 сервисов в Docker Compose за Nginx. Новое окружение поднимается за 10 минут вместо половины рабочего дня.
  • Настроил CI/CD в GitLab: линтеры, тесты на pytest, автоматический деплой после код-ревью.
  • Перенёс 60+ паролей и ключей доступа из кода и .env-файлов в HashiCorp Vault.
  • Ревьюю чужие merge request-ы и пишу документацию, по которой новые разработчики поднимают проект сами.
  • Разбираю инциденты на проде по логам и метрикам: нахожу причину, чиню и оставляю защиту, чтобы это не повторилось.

ЧТО СДЕЛАНО

  • Вход через OAuth Facebook: пароль клиента не проходит через сервис, токены доступа лежат в Secret Manager.
  • Защита бюджета: дневной лимит $50, каждая кампания стартует на паузе и не тратит деньги, пока клиент не подтвердит запуск.
  • Работа с Meta Marketing API: создание кампаний, групп объявлений и креативов, обработка лимитов и ошибок платформы, повторы запросов.
  • Автономный ИИ-агент на LLM через Vertex AI: разбор профиля и продукта, генерация текстов объявлений, подбор аудитории, вызов функций Meta API как инструментов агента.
  • Развёрнуто в Google Cloud: Cloud Run с автомасштабированием, база в Cloud SQL, сборка через Cloud Build и Artifact Registry, фоновые задачи в Cloud Tasks и Cloud Scheduler, логи и алерты в Cloud Logging и Monitoring.
