Пайплайны и хранилища

  • Разработал 15 и поддерживаю 38 DAG-ов в Apache Airflow. Каждый день они собирают ~12 млн строк из 17 источников: API ведомств, базы районных хокимиятов, выгрузки в XML и Excel.
  • Настроил ретраи, SLA и алерты о сбоях: 99,6% запусков проходят без ручного вмешательства, а упавший пайплайн команда видит в течение 5 минут.
  • Спроектировал схемы PostgreSQL для 9 предметных областей. Благодаря партиционированию и индексам ключевые запросы стали выполняться в 6 раз быстрее.
  • Перенёс аналитические агрегаты в ClickHouse (900+ млн строк). На материализованных представлениях отчёты строятся за 1,5 с вместо 40.
  • Встроил в каждый пайплайн проверки качества: полнота, дубликаты, соответствие схеме. Доля битых записей в витринах снизилась с 4% до 0,3%.
  • Заменил ручные выгрузки скриптами на Python и pandas. Аналитики экономят около 20 часов в неделю.

Интеграции и сервисы

  • Подключил 11 внешних сервисов по REST API, данные в JSON и XML проверяются по схеме.
  • Вынес тяжёлые задачи в очереди Celery, до 200 тыс. задач в сутки. Кэш на Redis сократил ответ внутреннего API с 1,2 с до 150 мс.
  • Передаю данные в реальном времени через WebSocket на панель операторов, задержка меньше секунды.
  • Подключил полнотекстовый поиск на Elasticsearch по 3 млн обращений граждан, ответ приходит быстрее 200 мс.

Инфраструктура

  • Упаковал 14 сервисов в Docker Compose. Новое окружение поднимается за 10 минут вместо половины рабочего дня.
  • Перенёс 60+ паролей и ключей доступа из кода и .env-файлов в HashiCorp Vault.
  • Храню сырые данные и бэкапы в AWS S3, отдельные ETL-задачи запускаю на EC2.
  • Настроил CI/CD в GitLab: линтер, тесты и автоматический деплой DAG-ов после код-ревью.
